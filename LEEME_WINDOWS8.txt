PUBLICAR DEPOSITOAPP CON GITHUB ACTIONS (SIN NODE.JS)
======================================================

La carpeta docs ya contiene la aplicacion web preparada. No necesita Node.js
8.8.1, Node 18 ni Git instalado en su computadora.

1) Ejecute SUBIR_A_GITHUB_SIN_NODE.bat.
2) En la pagina del repositorio de GitHub, use Add file > Upload files.
3) Suba TODO el contenido de la carpeta DepositoAPP (no suba la carpeta
   contenedora DepositoAPP como una carpeta adicional). Incluya docs y
   .github/workflows/publicar-pages.yml. Si GitHub no muestra .github,
   asegurese de que el ZIP fue extraido y cargue la carpeta .github también.
4) Pulse Commit changes y confirme en la rama main.
5) SOLO LA PRIMERA VEZ: en GitHub abra Settings > Pages > Build and deployment.
   En Source seleccione GitHub Actions.
6) Abra Actions y espere a que "Publicar DepositoAPP en GitHub Pages" termine
   con marca verde. El workflow publica docs automaticamente.
7) La aplicacion quedara en:
   https://automate9595-hub.github.io/DepositoAPP/

Configuracion Supabase:
La URL y la clave PUBLICABLE del proyecto ya están colocadas en docs/config.js.
No cambie ni comparta ninguna clave secret/service_role.

Si la carga se hace desde el navegador, GitHub puede requerir subir los
archivos visibles individualmente. Asegurese de incluir .github/workflows.
